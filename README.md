# 🪨✂️📄 Stone-Paper-Scissors Game (C++)

A **console-based Stone-Paper-Scissors game** built in C++ where the player competes against the computer. This project demonstrates **basic C++ concepts** such as enums, structs, functions, and clean, modular code.

---

## 🚀 Overview

- Play **multiple rounds** of Stone-Paper-Scissors against the computer.  
- Keep track of **round winners** and the **overall game winner**.  
- Uses **functions and structs** to organize game logic for readability and reusability.  
- Demonstrates **enum usage**, modular programming, and simple input/output handling.

---

## 🛠️ Tech Stack

- 🖥 **Language:** C++  
- ⚙️ **Tools:** Any C++ compiler (G++, Visual Studio, Code::Blocks, etc.)  
- 📌 **Focus Areas:** Functions, Structs, Enums, Loops, Conditional Statements, Modular Code  

---

## 💡 Features

- 🎯 Play a customizable number of rounds (1–10)  
- 🤖 Computer makes random choices  
- 🏆 Displays **round winner** and **overall game winner**  
- 🔄 Option to **play again** without restarting the program  
- 🧩 Modular code using **functions** and **structs** for each round and game info
